                               🌍📊 Earthquake & Geo-Spatial Data Analysis 🌍📊

An interactive **Tableau dashboard** analyzing historical earthquake data from **1900 to 2013** to identify earthquake locations, magnitudes, depth patterns, and geographical hotspots.

## 📌 Project Overview

This project analyzes **Magnitude 6+ earthquakes** recorded between **1900 and 2013** using Tableau's geographical and data visualization capabilities.

The analysis focuses on identifying earthquake hotspots, understanding the relationship between **depth and magnitude** for major earthquakes, and analyzing earthquake occurrences across countries and continents.

The project is presented from an **insurance industry perspective**, where historical earthquake patterns can support analysis of regions with higher earthquake activity.

## 🎯 Project Objectives

* Visualize earthquake locations across the world
* Analyze earthquake magnitude using geographical maps
* Study the relationship between earthquake depth and magnitude
* Analyze earthquakes with magnitude greater than 7
* Identify countries and continents with higher occurrences of major earthquakes
* Create an interactive dashboard and storyline for stakeholders

## 📁 Dataset

**Dataset:** `Mag6PlusEarthquakes.xlsx`

The dataset contains **Magnitude 6+ earthquakes from 1900 to 2013**.

Key analysis fields include:

* Latitude
* Longitude
* Magnitude
* Depth
* Place
* Country
* Continent

## ⚙️ Data Analysis

The project performs analysis across multiple dimensions:

* 🌍 **Geographical Earthquake Mapping**
* 📈 **Magnitude Analysis**
* 🌊 **Depth Analysis**
* 🗺️ **Country-wise Analysis**
* 🌎 **Continent-wise Analysis**
* 🔥 **Earthquake Hotspot Identification**

## 📊 Dashboard Features

### 🌍 Earthquake Map

A geographical visualization plots earthquake occurrences using **latitude and longitude**, with magnitude used to differentiate earthquake points.

### 📈 Depth vs Magnitude Analysis

A scatter plot is used to examine the relationship between **Depth and Magnitude** for earthquakes greater than 7 magnitude.

Tableau segmentation and non-aggregated measures are used to examine individual earthquake records.

### 🗺️ Country & Continent Analysis

The project extracts country information from the **Place** field and uses geographical visualizations and a tree map to analyze earthquake occurrences by country.

### 🔎 Interactive Data Selection

Tableau's **Lasso, Rectangular, and Radial selection tools** can be used to select earthquake points and export the selected records for further analysis.

## 💡 Key Insights

* Earthquake activity can be visualized geographically to identify regions with repeated occurrences.
* Magnitude and depth can be analyzed together for major earthquakes.
* Country-level analysis helps identify areas with higher numbers of major earthquake occurrences.
* Continent-level analysis provides a broader view of geographical earthquake activity.
* Interactive Tableau visualizations make historical earthquake patterns easier to communicate to stakeholders.
